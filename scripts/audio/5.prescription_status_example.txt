================================================================================
SUGGESTED ADDITIONAL FIELDS FOR PRESCRIPTION WORKFLOWS
================================================================================

The following fields would enhance this workflow:

1. prescription_type (string)
   - Example: "Antibiotic", "Pain Management", "Oral Rinse", "Fluoride"
   - Helps categorize and apply appropriate handling rules

2. controlled_substance (boolean)
   - Indicates if medication requires stricter refill protocols
   - Affects whether phone refills are allowed

3. days_supply (number)
   - Example: 30, 90
   - Used to calculate next_refill_date and detect early refill attempts

4. original_prescription_date (date)
   - When the prescription was first written
   - Helps determine if prescription has expired (typically 1 year)

5. prescription_expiration_date (date)
   - When the prescription itself expires (not just refills)
   - After this date, provider must write new prescription

6. prior_authorization_required (boolean)
   - Some medications require insurance pre-approval
   - Affects refill processing time

7. pharmacy_preference_updated (boolean)
   - Track if patient changed pharmacy during call
   - Useful for updating records

8. refill_request_notes (string)
   - Any special instructions or reasons for early refill
   - Passed to provider for review
